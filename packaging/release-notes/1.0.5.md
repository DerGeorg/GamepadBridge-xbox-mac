## There were two permissions, not one

Everything so far asked for Input Monitoring. Publishing a virtual gamepad
also needs **Accessibility**, and macOS mentions that in a way nobody can
act on: in German it announces the permission as *"Gerätesteuerung und
Datenzugriff"*, which matches no entry in the settings list. It is
Accessibility.

Both are now checked and requested, and the window shows which are still
outstanding, ticking each one off as it is granted.

## It asks again whenever it has to

Previously the permissions were checked once, at startup. If the system
refused the virtual gamepad later — after a controller connected, or after
a permission was revoked — the app simply stopped working and said so in a
status line.

Now any refusal puts it straight back into asking, with the window
explaining what is missing.

## Install

```sh
brew tap dergeorg/tap https://gitlab.dergeorg.at/mac/homebrew-tap.git
brew trust --cask dergeorg/tap/gamepadbridge
brew install --cask gamepadbridge
```

Or download `GamepadBridge.dmg` below. Signed and notarized; requires
macOS 15 or newer.
