## Runs on macOS 15 and 26 again

1.2.0 promised macOS 15 or newer but would only start on macOS 27: the app
was built for the macOS it was built on. It is now built for macOS 15, and
for Intel Macs as well as Apple silicon, as the README always said.
([#1](https://github.com/DerGeorg/GamepadBridge-xbox-mac/issues/1))

## Xbox Series controllers stay connected while idle

An Xbox Series controller (model 1914) left alone for 10 to 30 seconds
disconnected and came back a few seconds later. The adapter's firmware drops
a controller that sends nothing for a while unless it is told to wait
longer, and GamepadBridge never told it. It does now.
([#2](https://github.com/DerGeorg/GamepadBridge-xbox-mac/issues/2))

When a controller does disconnect, the log now says why — lost by the
adapter or disassociated by the controller — and how long it had been
quiet.

## Install

```sh
brew tap dergeorg/tap https://gitlab.dergeorg.at/mac/homebrew-tap.git
brew trust --cask dergeorg/tap/gamepadbridge
brew install --cask gamepadbridge
```

Or download `GamepadBridge.dmg` below. Signed and notarized; requires
macOS 15 or newer.
