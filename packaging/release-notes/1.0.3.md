## GamepadBridge now appears in the permission list by itself

1.0.2 opened the right Settings pane but left GamepadBridge out of the
list — and an app that is not listed cannot be switched on. You had to
find it yourself with the **+** button, which is not a reasonable thing
to ask of anyone.

Requesting the permission through `IOHIDRequestAccess` alone turns out
not to register the app. Opening a HID manager does, which is the other
path to the same request that IOKit documents. GamepadBridge now does
both, and asks again even when previously denied, because that is what
puts the entry there in the first place.

## The version is in the menu

The app has no window to put it in, and it is the first thing anyone is
asked in a bug report.

## Install

```sh
brew tap dergeorg/tap https://gitlab.dergeorg.at/mac/homebrew-tap.git
brew trust --cask dergeorg/tap/gamepadbridge
brew install --cask gamepadbridge
```

Or download `GamepadBridge.dmg` below. Signed and notarized; requires
macOS 15 or newer.
