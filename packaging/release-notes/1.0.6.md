## The permission window no longer covers the dialog it explains

It opened centred, which is exactly where macOS puts its own permission
prompts — so the window telling you what to do sat on top of the dialog
you were meant to answer. It now sits low on the screen, clear of them.

## Install

```sh
brew tap dergeorg/tap https://gitlab.dergeorg.at/mac/homebrew-tap.git
brew trust --cask dergeorg/tap/gamepadbridge
brew install --cask gamepadbridge
```

Or download `GamepadBridge.dmg` below. Signed and notarized; requires
macOS 15 or newer.
