## It now asks for the permission it needs

macOS will not let an app publish a virtual gamepad without Input
Monitoring, and it refuses silently: nothing is logged, no prompt appears,
and the app looks like it started correctly while the controller does
nothing at all.

GamepadBridge now asks for the permission on launch, and if that is not
possible it explains what is missing and opens the right Settings pane
directly — "Input Monitoring" is one of a dozen similarly named lists.

The app stays running while you grant it, on purpose: macOS only offers
its own **Quit and Reopen** for an app that is running when the switch is
flipped. Quitting first would leave you to find and start it again.

If the virtual gamepad is refused even with the permission granted, the
menu bar now says so instead of leaving it in a log.

## Updating

Running 1.0.1 or newer? This should arrive on its own — this is the first
release that does.

## Install

```sh
brew tap dergeorg/tap https://gitlab.dergeorg.at/mac/homebrew-tap.git
brew trust --cask dergeorg/tap/gamepadbridge
brew install --cask gamepadbridge
```

Or download `GamepadBridge.dmg` below. Signed and notarized; requires
macOS 15 or newer.
