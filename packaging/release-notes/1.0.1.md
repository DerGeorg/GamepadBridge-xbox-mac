## Automatic updates

GamepadBridge now updates itself through [Sparkle](https://sparkle-project.org).
It asks on first launch whether it may check on its own, and the menu bar has
a manual **Check for Updates** either way.

This is the last update you have to install by hand. 1.0.0 shipped without
Sparkle, so it has no way of hearing about this release — from here on it is
automatic.

Updates are signed with an EdDSA key separate from the app's code signature,
so an update is only installed if it came from us, whatever route it arrived by.

## Install

```sh
brew tap dergeorg/tap https://gitlab.dergeorg.at/mac/homebrew-tap.git
brew trust --cask dergeorg/tap/gamepadbridge
brew install --cask gamepadbridge
```

Or download `GamepadBridge.dmg` below. Signed and notarized; requires
macOS 15 or newer.
