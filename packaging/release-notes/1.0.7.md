## Y and Menu work in games under CrossOver and Steam

Games that read the controller through SDL — Windows games running under
CrossOver or Wine, and Steam — saw Y as X and Menu as RB. There was no way
to press Y, and no way to pause.

SDL decides how to read the buttons from the length of the report, and one
unused byte at its end made it pick the layout of a different controller.
That byte is gone. Games that ask macOS and games that ask SDL now read the
same buttons.

## Install

```sh
brew tap dergeorg/tap https://gitlab.dergeorg.at/mac/homebrew-tap.git
brew trust --cask dergeorg/tap/gamepadbridge
brew install --cask gamepadbridge
```

Or download `GamepadBridge.dmg` below. Signed and notarized; requires
macOS 15 or newer.
