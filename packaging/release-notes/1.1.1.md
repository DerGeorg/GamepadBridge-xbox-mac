## The menu keeps up while it is open

With the menu open, nothing in it changed: a controller that connected
showed up only after the menu was closed and opened again. It now updates
while it is open, and a controller's line — battery level included — is
shown in full instead of being cut off.

## Install

```sh
brew tap dergeorg/tap https://gitlab.dergeorg.at/mac/homebrew-tap.git
brew trust --cask dergeorg/tap/gamepadbridge
brew install --cask gamepadbridge
```

Or download `GamepadBridge.dmg` below. Signed and notarized; requires
macOS 15 or newer.
