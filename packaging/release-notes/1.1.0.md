## Several controllers at once

Every controller on the adapter is now a pad of its own — in games, in
System Settings and in the menu, where each one shows its battery level.
Until now a second controller simply took over the first one's pad.

## Rumble

Vibration reaches the controller: from macOS itself, and from games running
under CrossOver.

## The Xbox button

It does what it does on a real pad: macOS opens the Games app, and games
under CrossOver see the button.

## System Settings no longer fills up with controllers

Every start added another "Xbox Wireless Controller" to System Settings >
Game Controllers, because the virtual pad carried nothing macOS could
recognise it by. Each controller now keeps a single entry for good. The
ones left behind by earlier versions can be removed there once.

## Known limit: apps built on SDL 3.4

They read nothing from the pad — going by the SDL it ships, that includes
the Mac version of Steam. macOS marks every virtual device's connection as
"Virtual", and SDL 3.4 takes an Xbox pad that is not on Bluetooth for a
wired one. Games using macOS's own controller support are not affected, and
neither is Steam running under CrossOver.

## Install

```sh
brew tap dergeorg/tap https://gitlab.dergeorg.at/mac/homebrew-tap.git
brew trust --cask dergeorg/tap/gamepadbridge
brew install --cask gamepadbridge
```

Or download `GamepadBridge.dmg` below. Signed and notarized; requires
macOS 15 or newer.
